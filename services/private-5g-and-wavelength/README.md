# AWS Private 5G and AWS Wavelength

[Back to index](../../README.md)

| Criterion | AWS Private 5G | AWS Wavelength |
| --- | --- | --- |
| Purpose | Establish a private cellular network | Run AWS applications near a carrier's 5G users |
| Intended users | Businesses needing private cellular coverage | Developers and businesses serving low-latency mobile applications |
| Infrastructure | Private cellular networking hardware and software supplied through the service | AWS compute and storage deployed within telecommunications infrastructure |
| Example workloads | Factories, warehouses, campuses, IoT, robots, and internal cameras | AR/VR, gaming, video analytics, and connected vehicles |
| Network ownership goal | Build and operate a private cellular network | Use the carrier's network rather than build a private one |
| Main focus | Private network coverage | Low-latency edge computing |

The source refers to private “4G/5G” networks. This comparison describes the services' roles, not a guarantee of a particular radio technology, regional availability, or current service offering.
