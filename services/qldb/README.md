# Amazon Quantum Ledger Database

[Back to index](../../README.md)

Amazon Quantum Ledger Database (Amazon QLDB) is described in the source as a managed ledger database with an immutable change history that can be cryptographically verified.

| Use case | Ledger history |
|---|---|
| Banking and finance | Transactions and audit records. |
| Insurance | Contract and claim changes. |
| Supply chain | Shipment history. |
| HR and payroll | Salary and job-title changes. |
| E-commerce | Order and payment history. |
