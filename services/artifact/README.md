# AWS Artifact

[Back to index](../../README.md)

AWS Artifact provides access to AWS compliance reports and agreements.

- Reports include SOC reports and PCI compliance documentation.
- Agreements include business associate agreements (BAAs) for healthcare/HIPAA use and nondisclosure agreements (NDAs), as applicable.
- In the AWS console, open Artifact, accept the applicable terms, and download the report PDF for an audit.

## Notes

### Related services

| Service | Purpose |
|---|---|
| AWS Artifact | Access AWS compliance reports and agreements. |
| AWS Audit Manager | Collect compliance evidence from your AWS resources. |
| AWS AppConfig | Manage application configuration. |
